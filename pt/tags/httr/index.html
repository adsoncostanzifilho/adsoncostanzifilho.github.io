Pacote CSGo

Visão Geral GitHub: adsoncostanzifilho/CSGo O pacote CSGo é um cliente R para acessar a API REST da Steam, especificamente para dados do jogo Counter-Strike Global Offensive (CS Go). Confira o site de documentação da Steam e a página do pacote para mais informações. Instalação Para obter a versão atual publicada no CRAN: install.packages("CSGo") Para obter a versão de desenvolvimento atual do GitHub: # install.packages("devtools") devtools::install_github("adsoncostanzifilho/CSGo") Exemplo O primeiro passo para usar o pacote CSGo é ter suas próprias credenciais (API key) para puxar os dados do CSGo da API da Steam. Para mais informações sobre como obter sua própria API Key, execute no seu R vignette("auth", package = "CSGo") ou clique aqui. ...
